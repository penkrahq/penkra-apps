# Reading an App listing

Use this operation to inspect one exact registry App and version before install or update. It changes
no installation. Use the canonical reverse-domain App ID and an actual registry version; do not
substitute a slug, display name, source folder, or similarly named App.

Review the returned immutable version and every declared permission before proposing a state change.
A missing listing or version means that registry artifact is unavailable, not that a nearby version
or App may be substituted.
