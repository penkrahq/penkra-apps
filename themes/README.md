# Themes

Penkra's first-party Themes App.

Canonical App ID: `app.penkra.themes`.

Themes discovers, previews, applies, and manages Theme packages that conform to
Penkra's semantic token contract. A preview must be reversible, and Penkra safe mode
must be able to bypass a broken Theme.

Themes owns its complete web surface, including whether each page renders the
standard App Bar. It cannot style another App directly or override trusted shell
tokens outside the Theme contract.
